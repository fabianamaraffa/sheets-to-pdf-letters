1 · Prepare the Google Doc
1
Use a real Google DocIf you have a Word file, upload it to Drive, open it, then choose File → Save as Google Docs.
2
Write placeholders in double curly bracesYou can use them in the body, the header, the footer and inside tables.
Dear {{first_name}} {{last_name}},

Thank you for taking part in {{event}} on {{date}}.
Your certificate number is {{certificate_id}}.

Kind regards,
{{signatory}}
Placeholder rules
• Best with letters, numbers and underscores: {{first_name}}
• Upper and lower case count: {{Country}} is not {{country}}
• The same placeholder can appear several times
• Column names are matched automatically when they look alike (first_name ↔ First name)
3
Make sure you can open itThe tool runs with your own access, so the Doc does not need to be shared with anyone.
2 · When a cell is empty
Leave blank → replaced with nothing
Use default → replaced with a fallback text
Skip row → no PDF for that row
"Skip row" applies as soon as ANY placeholder set to skip is empty in that row. Use it for fields the letter cannot do without, like {{last_name}}.

4 · File name pattern
Letter_{{country}} → Letter_Italy.pdf
{{last_name}}_{{country}} → Rossi_Italy.pdf
Row{{row}}_{{country}} → Row1_Italy.pdf
{{row}} is the number of the data row (1 = first row under the headers). If a name already exists in the folder, _2, _3 and so on are added.
5 · Good to know
• Dates and numbers are copied exactly as they look in the sheet.
• PDFs are created a few at a time, so a long list can run for several minutes. You can stop at any moment and continue later with "Range".
• Always do a pre-flight and check the first PDF before launching a big batch.
